# nocur

テキストファイルを開き、変換内容を確認しながら編集するターミナルアプリです。変換を入力すると上側に結果が表示されます。`F2` / `Ctrl+X` で結果を確定し、`Ctrl+S` で確定と保存を行います。

短いチュートリアルは [nocur by example](BY_EXAMPLE.md) を参照してください。

## 起動

Rust 1.75 以上が必要です。プロジェクトのディレクトリで次を実行します。

```sh
cargo run -- examples/sample.txt
```

自分のファイルを開く場合は、パスを指定します。

```sh
cargo run -- path/to/notes.txt
```

起動時に指定したファイルは上書きされません。保存先は既定で、入力ファイル名に `.edited` を付けた別ファイルです。たとえば `notes.txt` を開いた場合、保存先は `notes.txt.edited` です。

## 画面の使い方

画面上部に変換結果のプレビュー、下部に入力欄があります。入力欄に変換を書き、プレビューを確認してから確定します。

1. 入力欄に変換を入力します。
2. 上部のプレビューで結果を確認します。入力途中で構文が不完全な場合は、エラーが表示され、プレビューには確定済みのテキストが表示されます。
3. 問題なければ `Ctrl+X` または `F2` を押します。プレビュー結果がHistoryに追加され、入力欄が空になります。
4. 確定と保存を一度に行うには `Ctrl+S` を押します。入力欄が空なら、確定済みテキストの保存だけを行います。

`F3` または `Ctrl+R` でHistory一覧を開きます。`↑` / `↓` または `Home` / `End` で選び、Enterでその時点のテキストに戻ります。Escで選択を取り消します。

たとえば、各行の前後の空白を取り除くには次を入力します。

```text
map(trim())
```

`F2` を押すと、この結果が次の変換の入力になります。続けて `filter(/TODO/)` と入力すれば、`TODO` を含む行だけをプレビューできます。

## 入力できる変換

変換を複数つなぐときは `|>` を使います。改行して書くこともできます。

```text
filter(/TODO:/)
|> map(replace(/TODO:/, ""))
|> map(trim())
```

この例は `TODO:` を含む行を残し、各行から `TODO:` と前後の空白を取り除きます。

| 入力例 | 動作 |
|---|---|
| `replace(/foo/, "bar")` | テキスト中の `foo` をすべて `bar` に置き換える |
| `replace("foo", "bar")` | `foo` という文字列をすべて置き換える（正規表現ではない） |
| `replace(lines(2..3), "x\n")` | 2〜3行目を置き換える |
| `replace(2:1-3:4, "x")` | 2行目1列目から3行目4列目までを置き換える |
| `delete(/draft/)` | `draft` に一致する部分を削除する |
| `trim()` | テキスト全体の先頭と末尾の空白を取り除く |
| `filter(/error/)` | `error` を含む行だけを残す |
| `lines(2..5)` | 2行目から5行目を取り出す |
| `map(trim())` | 各行の前後の空白を取り除く |
| `insert(1, "Title\n")` | 先頭に `Title` の行を挿入する |

文字列はダブルクォートで囲みます。改行を入れる場合は `\n`、タブは `\t` と書きます。正規表現は `/.../` で囲みます。大文字小文字を区別せずに `todo` を探すには `/(?i)todo/` と入力します。

`replace` の第1引数には `/.../`、`"..."`、`lines(開始..終了)`、`開始行:開始列-終了行:終了列` を指定できます。行と列は1始まりで、範囲の両端を含みます。列はUnicode文字単位で数えます。行範囲は連続したひとつの範囲として置換され、選択した行の改行コードも置換対象です。存在しない行や行の文字数を超える列を指定するとエラーになります。

`delete` と `filter` も `/.../` に加えて `"..."` の文字列指定を受け付けます。文字列指定では正規表現記号も通常の文字として扱います。

## キー操作

| キー | 動作 |
|---|---|
| `F2` | プレビュー結果を確定し、入力欄を空にする |
| `F3` / `Ctrl+R` | History一覧を開く。`↑` / `↓` で移動し、Enterで選択した状態に戻る |
| `Ctrl+X` | 入力中の変換をHistoryに追加して確定する |
| `Ctrl+S` | 入力中の変換を確定して保存する。入力が空なら保存だけを行う |
| `Ctrl+Z` / `Ctrl+Y` | 変換を undo / redo する |
| `Ctrl+E` | 確定した変換履歴を `<保存先>.transform` に書き出す |
| `Ctrl+Q` | 終了する |
| `Enter` | 入力欄に改行を入れる |
| `Tab` | 操作候補を補完する。`↑` / `↓` で候補を選べる |
| `←` / `→` | カーソルを移動する |
| `Home` / `End` | 行頭 / 行末に移動する |
| `Backspace` / `Delete` | 文字を削除する |
| `Ctrl+U` | 入力中の変換をすべて消す |
| `PageUp` / `PageDown` | プレビューを上下にスクロールする |

入力欄の変換は `F2` / `Ctrl+X` / `Ctrl+S` のいずれかを押すまでHistoryに入りません。`F2` と `Ctrl+X` は確定だけ、`Ctrl+S` は確定して保存します。終了時の自動保存はありません。
操作名を入力すると候補が表示されます。Tabで操作名と括弧を挿入し、括弧内には引数のヒントが表示されます。

## 保存した変換を再利用する

`Ctrl+E` で書き出した `.transform` ファイルは、`--eval` に読み込ませて再利用できます。たとえば入力ファイルが `notes.txt`、既定の保存先が `notes.txt.edited` の場合、履歴ファイルは `notes.txt.edited.transform` です。結果は画面に表示されます。

```sh
cargo run -- notes.txt --eval "$(cat notes.txt.edited.transform)"
```

結果をファイルに書き出すにはシェルのリダイレクトを使います。`>` はファイルを上書きし、`>>` は末尾に追加します。

```sh
cargo run -- notes.txt --eval "$(cat notes.txt.edited.transform)" >> todos.txt
```

## オプション

```text
cargo run -- FILE [--prompt TEXT] [--eval EXPRESSION]
```

| オプション | 説明 |
|---|---|
| `--prompt TEXT` | 入力欄のプロンプトを変更する。既定値は `:)` |
| `--eval EXPRESSION` | TUIを起動せず、変換結果を標準出力に出す |

入力できるファイルは UTF-8 のテキストで、サイズ上限は 8 MiB です。
